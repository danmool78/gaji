# 가지 설계

정해 둔 결정을 한곳에 모았습니다. 구현하면서 바뀌면 이 문서를 먼저 고칩니다.

## 1. 원칙
1. **껍데기만 서비스한다.** 가지 웹사이트에는 코드만 있고 데이터는 없다.
2. **동아리 하나 = 가지 홈 폴더 하나.** 데이터 · 보고서 · 사진 · 백업이 모두 그 안에 있다.
3. **한 화면에 한 가지 일.** 버튼은 많아야 3개, 상태는 색(초록 · 노랑 · 빨강)으로.
4. **가지(계보)가 중심.** 실험을 열면 그 실험의 가지가 항상 보인다.
5. **지우지 않는다.** 실험은 '취소'로, 파일은 휴지통으로만.

## 2. 역할
| 역할 | 누구 | 할 수 있는 일 |
|---|---|---|
| 시스템 마스터 | 가지 제작자 | 기능 업데이트. 동아리 데이터는 볼 수 없음 |
| 동아리 마스터 | 가지 홈 폴더 소유자 (공유 드라이브 관리자) | 모든 것, 최종 복구 |
| 관리자 | 설정 탭 관리자 목록 (2~3명 권장) | 부원 승인, 역할 변경, 관리자 넘기기(항상 1명 이상), 보관, 백업, 지원 요청 |
| 부원 | 공유 드라이브 참여자 | 기록 작성 · 수정 |

## 3. 드라이브 구조
```
가지 홈 폴더 (예: 공유 드라이브 "가지 - ○○동아리")
 ├ 📊 가지 데이터           (시트)
 ├ 📁 실험/<실험코드 제목>/  보고서 문서, 사진 (<코드>_01.jpg …)
 ├ 📁 보관/                 가지 보관 2026 … (연도별 시트)
 ├ 📁 백업/                 데이터 시트 주간 사본 (최근 몇 개만)
 └ 📁 로고 · 설정/
```
- 공유 드라이브 권장: 파일이 개인이 아니라 동아리 소유 → 졸업생 계정 삭제에도 안전.
- 개인 드라이브 동아리: 졸업 전 '소유권 정리' 안내.

## 4. 데이터 시트 탭
| 탭 | 내용 |
|---|---|
| 실험 | 실험 · 아이디어 · 질문 · 자료 한 줄씩 (id, 번호, 종류, 제목, 분야, 상태, 줄기, 날짜, 담당, 신호, 검토, 판정, 설명, 등록일, 수정일 …) |
| 연결 | 출발 · 도착 · 관계(이어서/파생/질문/자료/관련) |
| 측정 | 실험 · 조건 · 회차 · 값 · 제외 · 메모 |
| 번호 | 한 줄 추가할 때마다 그 줄 번호가 새 고유번호 → 동시에 눌러도 겹치지 않음 |
| 파일 | 파일 장부: 파일 ID · 종류 · 실험 번호 · 이름 · 만든 사람 · 날짜 (이름이 아니라 ID로 찾음) |
| 설정 | 동아리 이름 · 로고 · 색 · 분야 코드 · 관리자 목록 · 홈 폴더 ID · 시트 버전 (관리자만 편집: 범위 보호) |
| 기록 | 누가 무엇을 바꿨는지 |

- 고유번호: `EXP-20` (불변) / 실험 코드 `26-BIO-020` = 등록 연도 + 분야 + 번호 3자리.
- 긴 글(보고서)과 사진은 시트에 넣지 않는다 → 시트가 가볍다 (10년에 한도의 약 4%).

## 5. 속도와 한도
- 처음 열 때 탭별로 한 번에 읽고, 이후에는 '마지막 수정 시각'만 확인해 바뀐 탭만 다시 읽는다 (수십 초 간격).
- 학년도 마감 때 지난 기록은 보관 시트로 옮긴다. 계보가 필요할 때만 보관 시트를 읽는다.
- 구글 API 한도는 시스템 마스터 프로젝트 하나를 모든 동아리가 나눠 씀 → 요청을 묶고 줄인다. 커지면 무료 한도 증가 신청.

## 6. 권한 (구글)
- 로그인: 구글 계정. 권한 범위는 **"이 앱이 만들거나 고른 파일만"** (가장 좁은 범위).
- 부원은 처음 한 번 '동아리 시트 연결하기'로 파일을 고른다. 동아리 링크(`?club=<시트 ID>`)로 들어오면 안내.
- 드라이브에서 직접 넣은 파일은 '드라이브에서 가져오기'로 한 번 골라야 가지가 볼 수 있다.

## 7. 지우기 실수 대비
| 겹 | 방법 |
|---|---|
| 막기 | 부원은 참여자 권한, 설정 · 파일 탭 범위 보호, 가지 안에서는 삭제 대신 취소 |
| 되살리기 | 드라이브 휴지통 30일, 시트 버전 기록 |
| 백업 ① | 관리자가 가지를 열 때 주 1회 '백업' 폴더에 데이터 시트 사본 |
| 백업 ② | 같은 때 관리자 **개인 드라이브**에도 사본 (공유 드라이브가 통째로 지워져도 남음) |
| 백업 ③ | '주간 백업 메일 켜기' → 동아리 드라이브의 Apps Script 예약 실행이 매주 관리자들에게 데이터 엑셀(.xlsx) + 변경 요약 메일 |
| 복구 | '백업에서 복구' → 새 데이터 시트로 되살림, 번호 이어짐 |
| 알림 | 시트 · 홈 폴더가 안 보이면 복구 안내 화면, '파일 점검'으로 사라진 파일 목록 |

## 8. 지원 요청 (제작자도 기록을 못 보므로)
- 설정 탭 '제작자에게 지원 요청' → 기간(3 · 7 · 14일) 선택 → 데이터 시트 **읽기 전용** 공유, 기간 지나면 자동 해제, '지원 종료'로 즉시 해제, 기록 탭에 남김.
- 학교가 외부 공유를 막으면 '지원용 사본 내보내기'(엑셀, 이름 가리기 선택).
- '오류 보고': 실험 내용 없이 오류 메시지 · 화면 · 버전만.

## 9. 업데이트
- 설정 탭의 `시트 버전`을 보고, 새 버전의 가지가 예전 시트를 자동으로 새 구조로 바꾼다 (열 추가 위주, 지우지 않음).
- 예전 버전 화면이 새 구조 시트를 열어도 깨지지 않게, 모르는 열은 무시한다.
