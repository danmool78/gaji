## 소리 붙이기 (선택)
녹음 파일(`voice.m4a` 등)이 있으면 아래 한 줄로 영상에 붙일 수 있어요. 또는 캡컷 · 블로 같은 앱에서 영상과 녹음을 나란히 놓고 맞추면 됩니다.

```
ffmpeg -i intro/out/가지-소개-가로.mp4 -i voice.m4a -c:v copy -c:a aac -shortest intro/out/가지-소개-가로-소리.mp4
```

## 다시 만들기
```
node intro/capture.cjs        # 체험 화면을 가로형 태블릿 크기로 다시 찍기 (앱이 바뀌었을 때)
node intro/record.cjs         # 가로 영상
node intro/record.cjs short   # 쇼츠
BY="실험동아리 기장 후보 ○○○" node intro/record.cjs   # 마지막 화면에 한 줄 넣기
```
브라우저로 `intro/index.html`, `intro/short.html`을 열면 영상과 같은 화면이 바로 재생돼요 (발표 때 화면으로 틀어도 됨).
