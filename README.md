# 가지 (GAJI)

**실험이 가지를 치며 이어지는 곳.** 고등학교 실험 동아리를 위한 연구 관리 도구입니다.

계획서, 준비, 측정, 결과, 그리고 다음 실험까지 한 줄기로 이어서 기록합니다. 실패한 실험도 다음 실험의 씨앗으로 남습니다.

- 사이트: https://gaji-lab.web.app (Firebase Hosting, 동아리 주소 예: `/c/동아리주소`)
- 지금 상태: **체험 모드** (예시 데이터, 바꾼 내용은 각자 브라우저에만 저장)

## 화면

| 탭 | 내용 |
|---|---|
| 홈 | 지금 챙길 것 3개, 큰 버튼 3개(새 실험 · 아이디어 · 질문), 진행 중인 가지 |
| 가지 | 연구 줄기 카드 목록. `줄기별 ↔ 날짜별` 전환. 카드를 누르면 줄기 전체가 세로 가지로 펼쳐짐 |
| 찾기 | 제목 · 번호(예: `CHE-019`) 검색, 종류별 보기 |
| 더 보기 | 설정(동아리 이름 · 로고 · 색 · 화면 밝기), 보드, 전체 지도(발표용), 소개 |

실험 상세에는 **이 실험의 가지**(계보)와 **관련된 것**(위 질문 · 왼쪽 자료 · 오른쪽 다음 · 아래 이전)이 항상 보입니다.

## 운영 구조 (목표)

```
가지 사이트 (Firebase Hosting)  ← 시스템 마스터: 기능 · 동아리 사용 현황 숫자만
  gaji.web.app/c/<동아리 주소>
      │
      ▼
동아리 구글 드라이브 (학교 공유 드라이브 권장)  ← 동아리 마스터 1명
  ├ 가지 데이터 (시트) · 동아리 연결기 (Apps Script)
  ├ 실험/ 보고서 · 사진   ├ 보관/   └ 백업/
```

- 서버 비용 0원. 실험 데이터는 각 동아리 드라이브에만 있고 **제작자도 볼 수 없습니다.**
- Firebase에는 동아리당 **마스터 한 명의 계정 ID**와 사용 현황 숫자만 저장합니다.
- 부원은 **학번 + 개인 코드**로 쓰고, 새 기기는 카톡으로 요청 → 기장이 승인.
- 자세한 설계: [`docs/설계.md`](docs/설계.md)

## 시험

```
node tests/connector.test.cjs          # 연결기 로직 (68개)
firebase emulators:exec --only firestore "node tests/rules.test.cjs"   # 보안 규칙 (34개)
```
